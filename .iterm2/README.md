# iTerm2 preferences

iTerm2 loads and saves its preferences in this folder; how the script points
it here and what that means for the committed plist is in the iTerm2 section
of the main README.

`ayu dark.itermcolors` is the old colour-scheme export, kept as a reference.
The colours in use live in the profile inside the plist.

This folder is dot-prefixed, so chezmoi never writes it into the home
directory.
