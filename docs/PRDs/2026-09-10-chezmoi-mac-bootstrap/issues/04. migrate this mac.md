# Migrate this Mac

## PRD

[2026-09-10-chezmoi-mac-bootstrap](../prd.md)

Captured values, commands and sources are in [research-notes.md](../research-notes.md).

## What to build

Make the personal Mac the first machine kept in sync, reviewing every change before it lands. The repo files written by the earlier issues are the source of truth: nothing is adopted from the home directory, which would overwrite them with the stale versions. The steps are in the order they have to run.

- **Config first, then re-init.** `~/.config/chezmoi/chezmoi.toml` on this Mac already stores `personal = false`, and `.chezmoi.toml.tmpl` asks through `promptBoolOnce`, which keeps a stored answer: a second `chezmoi init` does not ask again, and `chezmoi init --promptBool personal=true` does not change the stored value either (both verified in an isolated HOME). So edit the file by hand first (`personal = true`, `embedded` as wanted), then run `chezmoi init --source ~/repos/caillou/dotfiles` to regenerate it from the current template, which keeps the edited values, points chezmoi at the repo and clears the "config file template has changed" warning. Confirm with `chezmoi data | grep personal`. Applying with `personal = false` would leave out every personal formula, cask and App Store app, and the documented `brew bundle cleanup` check would then propose removing them all.
- **Backup, before anything is changed, removed or applied.** `tmutil localsnapshot` first: one command, it covers everything below and restores per file. Then `defaults export` every domain the defaults script writes, because cfprefsd caches them and a tar of the plist files can be stale: `NSGlobalDomain`, `com.apple.finder`, `com.apple.dock`, `com.apple.WindowManager`, `com.apple.screencapture`, `com.apple.HIToolbox`, `com.apple.desktopservices`, `com.apple.AppleMultitouchTrackpad`, `com.apple.driver.AppleBluetoothMultitouch.trackpad`, `com.apple.assistant.support`, `com.apple.speech.recognition.AppleSpeechRecognition.prefs` and `com.apple.symbolichotkeys` (it holds every custom keyboard shortcut and the script replaces the whole domain), plus `com.googlecode.iterm2` and `defaults -currentHost export NSGlobalDomain`. Then `tar` every target listed by `chezmoi managed`, all of `~/.config/fish` (fisher 3 owns files there that `chezmoi managed` does not list), `~/.DS_Store`, `~/.nvmrc` and `~/.asdf/shims` into a dated archive outside the repo; chezmoi keeps no backups and the universal-variable purge hits all open fish sessions at once.
- **iTerm2 fonts.** Install the `font-anonymice-nerd-font` cask, set the profile's non-ASCII font to `AnonymiceProNerdFontMono-Regular 16` in iTerm2, delete the 2023 `Anonymice Nerd Font Complete Mono.ttf` and the unused `BlexMonoNerdFont-*.ttf` files from `~/Library/Fonts`, confirm the Pure prompt glyphs still render.
- **iTerm2 export.** Both profiles carry `Working Directory = /Users/caillou` (lines 893 and 1344 of `defaults export com.googlecode.iterm2 -`), and only the four custom-folder and NoSync keys are excluded from what iTerm2 writes out. Set each profile's working directory to "Home directory" (Profiles > General) and quit iTerm2 before exporting the preferences into `.iterm2/` in the repo. Afterwards `grep -n '/Users/' .iterm2/com.googlecode.iterm2.plist` must print nothing and `file .iterm2/*.plist` must say XML. Run `tests/secrets-check.sh` before committing the plist.
- **Confirm, never adopt.** The three Hammerspoon files and the Karabiner source in the repo have to match the live ones (diff, not `chezmoi add`).
- **Retire fisher 3 before the first apply.** This Mac runs `fisher version 3.2.9` from `~/.config/fish/functions/fisher.fish`, with a `fishfile` and no `fish_plugins`. Script 20's guard is `functions --query fisher`, which is true under fisher 3, so it skips the bootstrap and runs `fisher update`, a subcommand fisher 3 does not have: "fisher update failed" on every apply, forever, and fisher 4 refuses to install over fisher 3's files. So, after the backup, `fish -c 'fisher self-uninstall'` (it removes its packages and itself; the Pure prompt is gone until the scripts apply), then remove the old `fishfile`. Do this before the universal-variable purge, since fisher 3 keeps its package list in one.
- **Purge the dead fish universal variables** listed in the research notes (BrowserStack, pyenv, Spacefish, colours, init markers); the settings kept already live in the conf.d file from the shell issue. Remove `~/.nvmrc`.
- **Remove the two Hammerspoon symlinks:** `rm ~/.hammerspoon/keyboard ~/.hammerspoon/Spoons/EmmyLua.spoon`. chezmoi replaces `init.lua` only, nothing in the managed config loads a Spoon, and both symlinks dangle the moment `~/repos/keyboard` goes.
- **Apply the files**, reviewing with the user: `chezmoi diff`, then `chezmoi apply --exclude scripts` (gitconfig, with the ICFM override taking effect immediately for `~/repos/icfm`; the shell files; `init.lua`, `windows.lua` and `status-message.lua` in `~/.hammerspoon`). Open a new fish and check the abbreviations, `node --version` and that the shell is otherwise healthy; the prompt is still bare at this point, because fisher 4 arrives with the scripts. Reload Hammerspoon, check the console shows no errors and the Ctrl+S layout modal works.
- **Apply the scripts:** `chezmoi apply`. Expect script 20 to bootstrap fisher 4 and install the four `fish_plugins` entries, so a new fish has the Pure prompt, z and the fzf bindings back; the defaults script to restart Finder, Dock and SystemUIServer; one Automation consent prompt, for System Settings, which the defaults script quits by Apple Event (every sender and target pair prompts once, and the System Events prompt for the wallpaper is skipped here because the wallpaper is already a solid colour); the display script to import once rather than do nothing, because two of the four display entries carry no `AutoBrightnessEnable` key, so it writes the flag, imports, restarts `corebrightnessd` and may flicker the brightness; and sudo prompts for pmset and for the display export and import.
- **Apply once more.** The display script must now say auto-brightness is already off, import nothing and restart no daemon, and `chezmoi diff` must be empty. If it imports on every run, `corebrightnessd` is dropping the flag from entries it does not manage and the read-back has to tolerate keyless entries.
- asdf: the managed shell files no longer source the git-clone install; keep `~/.asdf` as data dir; after the apply installed Homebrew asdf and ran `asdf reshim`, confirm node and python resolve in a new shell.
- Karabiner: already on "Default profile" (done 2026-09-11). Confirm the build from `.karabiner/` produces rules identical to the current ones.
- Archive `caillou/keyboard` and `caillou/karabiner.ts` on GitHub (`gh repo archive`) after adding a README line pointing at dotfiles; remove `~/repos/keyboard` and `~/repos/caillou/karabiner.ts`.
- Verify afterwards: prompt and abbreviations unchanged, git identity per folder, Downloads view intact, Dock unchanged, Karabiner remaps and Hammerspoon layout work, nothing else visibly different. Rollback is the snapshot, the exported domains and the tar archive.
- Done 2026-09-14. The ICFM identity post-check has to run inside a repo under `~/repos/icfm/`; the container directory itself reports the personal address. The two local keyboard checkouts are removed by hand after the archive.
